## 架构速览

墨墨的核心由三层组成：

```
  ┌────────────────────┐
  │  分身层 (Avatars)   │  领域专家：医疗/金融/教育/...
  │  你在这里写代码     │
  ├────────────────────┤
  │  感知层 (Senses)    │  感官：视觉/听觉/天气/...
  │  你在这里注册感官   │
  ├────────────────────┤
  │  运行器 (Runner)    │  心跳/调度/路由/守护进程
  │  框架已提供         │
  └────────────────────┘
```

**运行流程：**

```
用户输入 → 感官处理 → 路由到最合适的分身 → 返回回应
```

## 创建你的第一个分身

分身 = 一个 Python 类，包含 `process()` 和 `help()` 方法。

```python
# my_avatar.py
from momo.runner import MomoRunner


class MyAvatar:
    """你的第一个分身"""

    def process(self, text: str) -> dict:
        """处理输入并返回回应"""
        # 你的逻辑写在这里
        return {"response": f"你说的是: {text}", "confidence": 0.9}

    def help(self) -> dict:
        """能力说明"""
        return {
            "name": "我的第一个分身",
            "description": "示例分身",
            "capabilities": ["回显用户输入"],
        }


# 注册并运行
runner = MomoRunner()
runner.register_avatar("my_skill", MyAvatar())
runner.start()

resp = runner.interact("你好")
print(resp["response"])  # → "你说的是: 你好"

runner.stop()
```

## 创建你的第一个感官

感官 = 一个 Python 类，包含 `process()` 方法，输入文本，输出结构化感知数据。

```python
class MoodSense:
    """语气/情绪感官"""

    def process(self, text: str) -> dict:
        positive = ["好", "棒", "喜欢", "开心", "nice", "good"]
        negative = ["坏", "差", "讨厌", "生气", "bad", "sad"]

        mood = "neutral"
        for word in positive:
            if word in text.lower(): mood = "positive"; break
        for word in negative:
            if word in text.lower(): mood = "negative"; break

        return {"mood": mood, "words_analyzed": len(text.split())}
```

## 分身与感官的注册 API

```python
runner = MomoRunner()

# 注册分身（会在交互时自动路由）
runner.register_avatar("name", avatar_instance)

# 注册感官（会在交互时自动感知）
runner.register_sense("name", sense_instance)

# 启动（后台守护进程开始运行）
runner.start()

# 交互（自动经过所有感官 → 路由到匹配的分身）
resp = runner.interact("你的文字")

# 查看状态
stats = runner.status()

# 停止
runner.stop()
```

## 最佳实践

### 分身设计

1. **一个分身做好一件事** — 不要试图覆盖太多领域
2. **返回 `"response"` 字段** — 这是 Runner 读取的回应
3. **可选返回 `"confidence"`** — 路由时高置信度优先
4. **实现 `help()` 方法** — 方便文档生成和调试

### 感官设计

1. **不要阻塞** — `process()` 应该快速返回
2. **结构化输出** — 返回 dict，而不是字符串
3. **出错也返回** — 而不是抛出异常

### 项目结构

```
你的项目/
├── my_avatar.py       # 你的分身
├── my_sense.py        # 你的感官
└── main.py            # 启动脚本
```
