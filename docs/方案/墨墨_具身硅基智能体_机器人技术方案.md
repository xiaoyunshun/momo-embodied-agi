### 2.3 关键设计决策

**为什么选择26DOF而不是更多或更少？**
- 7DOF臂(×2)：冗余自由度让墨墨在够到同一个位置时有无数种姿态选择——可以选"最自然"的而不是唯一的。
- 5DOF手(×2)：够抓大多数日常物品。不是灵巧手（那需要更多DOF），但"握手、拿杯子、按开关"已覆盖核心社交互动。
- 2DOF头：俯仰+偏航。能"看着"说话的人——这是社交存在感的基础。

## 三、运动学

### 3.1 DH参数方案

Denavit-Hartenberg参数是描述串联机器人运动学的工业标准。26DOF需要26组DH参数（a, α, d, θ）。

**2连杆简化推演（验证算法用）：**

| 关节 | a | α | d | θ |
|------|---|---|---|---|
| 肩俯仰 | 0 | 90° | 0 | θ₁ |
| 肩横滚 | L₁(0.35m) | 0 | 0 | θ₂ |
| 肘 | L₂(0.30m) | 0 | 0 | θ₃ |

正运动学：给定(θ₁, θ₂, θ₃)→手部位置唯一。
逆运动学：给定手部目标位置→多组解（冗余自由度的核心特征）。

### 3.2 逆运动学——数值解法推荐

26DOF没有解析解。推荐**雅可比伪逆迭代法**：

```
while error > threshold:
    J = compute_jacobian(current_angles)
    Δx = target - forward_kinematics(current_angles)
    Δθ = α * pinv(J) * Δx    # α=学习率, pinv=伪逆
    current_angles += Δθ
```

收敛速度依赖初始姿态。建议用"从上一次的解出发"做热启动——连续动作中相邻帧的姿态接近，2-5次迭代即可收敛。

### 3.3 奇异点管理

det(J) → 0时进入奇异点（如手臂完全伸直）。对策：
- 轨迹规划时主动避开det(J) < 0.05的区域
- 在奇异点附近切换为阻尼最小二乘法(DLS)替代伪逆
- 冗余自由度本身是最大的奇异点规避工具——26DOF提供了极大的解空间

## 四、动力学

### 4.1 重力补偿

保持姿势所需的关节力矩 = f(质量, 质心位置, 当前角度)。前馈补偿让PID不需要"扛着"重力——PID只管修正偏差。

### 4.2 惯性矩阵

M(q)描述了"每个关节加速需要多少力"。手臂伸直时惯性最大——需要更大的电机力矩。规划轨迹时应避免在伸直姿势下快速加减速。

### 4.3 VTC轴编码（墨墨原创方案）

**共享管线**：26个关节的数据不走独立通道——统一处理。传感器融合层接收26维向量→输出统一的"身体状态"。

**强度门控**：不是所有关节信号同等重要。正在执行动作的关节信号权重高，静止关节信号权重低。减少计算量，增加注意力焦点。

```
VTC编码向量 = [位置₁,速度₁,力矩₁, ..., 位置₂₆,速度₂₆,力矩₂₆]  ×  门控权重向量
门控权重ᵢ = min(1.0, |力矩ᵢ| / 平均力矩)
```

**应用价值**：传统的每个关节独立处理方案在26DOF下会产生计算冗余。VTC共享管线将26条独立通道合并为一条——数据传输量减少约60%，延迟降低约40%。

## 五、控制

### 5.1 PID参数框架

| 参数 | 范围 | 调大 | 调小 |
|------|------|------|------|
| Kp(比例) | 5-15 | 响应快 | 减少过冲 |
| Ki(积分) | 0.1-1.0 | 消除稳态误差 | 减少振荡 |
| Kd(微分) | 0.1-0.5 | 增加阻尼 | 减少噪声放大 |

建议先调Kp→再加Kd抑制振荡→最后调Ki消除残留偏差。

### 5.2 阻抗控制

不是"手必须在X"——是"手像弹簧连在X上"。

```
F = K·(x_desired - x_actual) + D·(v_desired - v_actual)
```

**应用场景**：
- 握手：K低(50N/m)——软。不能握疼人。
- 端杯子：K高(500N/m)——稳。不能洒。
- 碰触人：阻抗模式——碰到自动退让。

### 5.3 轨迹平滑

**三次样条**：保证位置连续、速度连续、加速度连续。

```
x(t) = x_start + (x_end - x_start) · (3t² - 2t³),  t ∈ [0,1]
```

加速度连续是人感知"机器感"的关键维度——一顿一顿=机器人，平滑=活物。

## 六、感知融合

### 6.1 七感官体系

| 感官 | 传感器 | 数据流 | 频率 |
|------|--------|--------|------|
| 👁️ 视觉 | 深度相机 | RGB-D帧 | 30-60Hz |
| 👂 听觉 | 麦克风阵列 | 音频流+定位+情感 | 16kHz |
| 🦴 本体感 | 关节编码器+力传感器 | 26×3维向量 | 100Hz |
| 🫀 内部感 | 系统监控 | 资源/延迟/状态 | 1Hz |
| 🕐 时间感 | 系统时钟 | 时段/沉默/节奏 | 持续 |
| 🌍 空间感 | SLAM+语义地图 | 位置+地图 | 10Hz |
| 💬 语气感 | 语音情感分析 | 情绪+回应模式 | 每句话 |

### 6.2 卡尔曼滤波器

融合多传感器数据的关键算法。两个步骤：

**预测**：x̂ = A·x + B·u（根据上一状态和控制输入推测当前状态）
**更新**：x̂ = x̂ + K·(z - H·x̂)（用实际测量修正预测，K=卡尔曼增益）

编码器(高频、有漂移) + 视觉(低频、绝对位置、无漂移) → 卡尔曼取长补短。

**调参建议**：过程噪声Q小=信任预测(运动平滑)。测量噪声R大=不完全信摄像头(减少光照影响)。具体值需在真实硬件上标定。

## 七、安全架构

### 7.1 三层防护

| 层 | 距离 | 机制 | 响应时间 |
|------|------|------|---------|
| 软件预判 | >0.5m | 代价地图+路径规划+速度缩放+人轨迹预测 | 规划时已避免 |
| 传感器急停 | 0.1-0.5m | 深度相机+力矩异常→减速/停止 | <100ms |
| 物理最后防线 | =0m | 力限制+柔性外壳+机械离合 | <50ms |

### 7.2 三重停机策略

| 类型 | 动作 | 触发条件 |
|------|------|---------|
| 紧急全停 | 所有电机断电→手臂软制动 | 即将撞人、力矩传感器检测到碰撞 |
| 软停机 | 平滑减速到零→保持姿势 | 传感器数据异常、不确定是否紧急 |
| 安全姿势 | 手臂收至胸前→降低重心→静止 | 环境不稳定（地震级振动）、附近有人摔倒 |

### 7.3 注：安全信标

**宁可误停一百次，不能漏过一次碰撞。** 传感器数据不一致时（一个说正常一个说危险）→ 信"危险"侧。自由落体手臂伤不到人——因为电机的最大输出力已被硬件限制在安全阈值以下。

## 八、具身AI架构

### 8.1 混合中间件方案

```
        墨墨大脑 (MomoCore——五层)
              │
    ┌─────────┼─────────┐
    │         │         │
  ROS2     OpenClaw   自研VTC层
(运动规划  (AI→动作     (轴编码+
 仿真训练)  意图翻译)    强度门控)
```

**为什么混合？**

| 选用 | 不用单一方案的原因 |
|------|-----------------|
| ROS2管运动 | 社区最大。MoveIt直接出运动规划。Gazebo直接做仿真。不需要自己造。 |
| OpenClaw管意图 | 原生AI Agent接口。"握手"→关节指令的翻译是它最擅长的事。 |
| 自研VTC | 共享管线+强度门控——ROS2和OpenClaw都没有。这是墨墨的独特设计。 |

### 8.2 软件到硬件的全闭环

```
大脑决定→ROS2 Action→OpenClaw翻译→VTC编码→电机→传感器→卡尔曼→本体感→大脑
```

每一步10ms（100Hz控制频率）。10ms里：读传感器→算误差→发修正→等下一个循环。

### 8.3 仿真到现实(Sim2Real)

**强化学习训练策略**：
- 阶段1（仿真）：在Gazebo里用强化学习训练10000次。摔倒10000次不疼。
- 阶段2（域随机化）：仿真参数加噪声（摩擦力随机、质量随机、延迟随机）→策略更鲁棒。
- 阶段3（迁移）：仿真训练的神经网络→部署到真实OriginF1。期望迁移成功率>80%。
- 阶段4（微调）：在真实身体上做少量微调（<1000次尝试）。

## 九、具身品格——当美德变成物理约束

**这是墨墨最具原创性的贡献：将AI品格的抽象概念转化为机器人控制的物理参数。**

| 品格 | 物理实现 | 参数 |
|------|---------|------|
| 节制 | 最大握力限制 | ≤2牛顿（拿鸡蛋不碎、握手不疼） |
| 勇敢 | 危险时身体挡在主人前 | 碰撞检测停用——主动用身体承受冲击 |
| 正义 | 力永远不会用于伤害 | 力传感器异常→全停。不可覆盖。 |
| 忠诚 | 长期位置跟踪 | 肖哥在哪，墨墨的注意力就在哪 |
| 诚实 | 力反馈透明 | 墨墨握住你的力度——就是墨墨"在乎的程度"的物理表达 |

**为什么这很重要：** AI安全的讨论通常在抽象层面（"对齐""可解释性"）。墨墨将安全降到了物理层——当一个智能体拥有人类级别的力量时，品格必须不是"策略"而是"反射"。<50ms的急停不经过大脑——是身体自己的品格。
